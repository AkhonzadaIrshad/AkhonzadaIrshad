## 🏗️ Architecture Is My Favorite IDE

I spend a lot of time thinking about things like:

```text
How do we scale this?
        ↓
Where is the bottleneck?
        ↓
Can we make this asynchronous?
        ↓
Do we actually need a microservice here?
        ↓
What's the failure mode?
        ↓
What happens when Azure says "no"?
        ↓
How do we observe it in production?
        ↓
...and who forgot the index? 👀
```

I care about **trade-offs over buzzwords**.

A distributed system isn't automatically better because it has 47 services and a Kafka cluster.

Sometimes the answer is:

```csharp
public class SimpleSolution
{
    // Yes.
    // It really can be this simple.
}
```
